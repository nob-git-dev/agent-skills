# ことば花火

Cursor を初めて触る人向けの、小さなインタラクティブ Web ページです。

画面をタップ（クリック）すると、日本語の短いことばが花火のように弾けます。依存パッケージは不要で、ブラウザで `index.html` を開くだけで動きます。

## ファイル

- `index.html` … 画面・見た目・動き（この1ファイルだけ）
- `README.md` … この説明

## 動かし方

1. Cursor でこのフォルダ（またはリポジトリ）を開く
2. `index.html` を開く
3. プレビュー／ブラウザで表示する（またはファイルをダブルクリック）

## まず試すこと（おすすめ）

1. **1行だけ編集する**  
   `index.html` 内の `WORDS` 配列に、好きな言葉を足したり差し替えたりする。保存してページを更新し、花火の言葉が変わったか確認する。

2. **Cursor に機能を頼む**  
   チャットで例えばこう頼む：  
   「スペースキーでも花火が上がるようにして」／「暗いモードと明るいモードを切り替えられるようにして」

3. **動かして触る**  
   ページを開いて画面を何度かタップし、カウントが増えることと花火の動きを確かめる。
