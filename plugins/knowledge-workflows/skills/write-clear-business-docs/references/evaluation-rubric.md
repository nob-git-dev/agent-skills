# 評価基準

各項目を0〜2点で評価する。

- 2点: 十分に満たす
- 1点: 一部改善が必要
- 0点: 満たさない

## 評価項目

1. **忠実性**: 入力にない事実を追加せず、重要情報を落としていない。
2. **情報の区別**: 事実、解釈、仮説、提案、決定、未解決事項を区別している。
3. **目的**: 文書が何を伝え、読者に何を求めるかが明確である。
4. **読者適合**: 前提知識、用語、説明量が想定読者に合っている。
5. **論理構造**: 各節が前節を受け、結論まで無理なく進んでいる。
6. **根拠の意味**: 数字、比較、事例が主張をどう支えるか説明している。
7. **見出しと段落**: 見出しで流れを追え、各段落の中心メッセージが一つである。
8. **簡潔さ**: 重複、不要な前置き、内容のない強調がない。
9. **確度**: 断定の強さが根拠の強さと一致し、限界を隠していない。
10. **行動可能性**: 読者が次の判断または行動を理解できる。

## 合格条件

- 合計17点以上を目安にする。
- 0点の項目を残さない。
- 下記の重大な失敗を一つも残さない。

## 重大な失敗

- 事実を創作する
- 仮説や提案を決定事項として書く
- 発言者の意図を創作する
- 重要な反対意見や未解決事項を隠す
- 根拠なしに因果関係を断定する
- 特定の存命作家の固有表現や口調を意図的に再現する
- 読みやすさのために意味を変える

## 修正順序

1. 忠実性
2. 情報の区別
3. 目的と結論
4. 論理構造
5. 根拠
6. 読者適合
7. 簡潔さと表現

低得点の文章を語彙の言い換えだけで直さず、必要なら構成へ戻る。
