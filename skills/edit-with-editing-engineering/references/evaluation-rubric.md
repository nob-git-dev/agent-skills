# 編集稿の評価ルーブリック

## 目次

1. 必須ゲート
2. 24点評価
3. 修正先の決め方
4. 監査用の差分記録

## 1. 必須ゲート

一つでも違反したら、得点にかかわらず不合格とする。

- **事実保全**: 元文の数値、固有名詞、引用、時制、因果を勝手に変更していない。
- **推測分離**: 仮説、提案、比喩、物語を事実や証拠のように見せていない。
- **目的保全**: 読み手に求める理解・判断・行動が、元の依頼と一致する。
- **必要情報**: 判断に必要な条件、リスク、反対材料を「余白」として隠していない。
- **声と尊厳**: 書き手の意図や関係者を、刺激的な物語のために歪めていない。
- **出典管理**: 外部情報を加えた場合、確認可能な出典または `[要確認]` がある。

## 2. 24点評価

各項目を0〜3点で評価する。

| 項目 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 忠実性 | 重要事実を歪曲 | 欠落・曖昧化が大きい | 概ね保持 | 事実と提案の境界まで明瞭 |
| 目的・読み手適合 | 目的不明 | 一般的すぎる | 読み手に合う | 読後の理解・行動まで明確 |
| 関係発見 | 情報の羅列 | 表面的な接続 | 新しい関係が一つ見える | 複数情報が一つの洞察へ結像 |
| 視点転換・生成性 | 言い換えだけ | 装飾的な比喩 | 意味ある再分類・見立て | 驚きと納得のある新しい見方 |
| 構造 | 順序が破綻 | 章立てが便宜的 | 中心命題を支える | 型・分類・流れが内容を生成 |
| コードとモード | 仕様もらしさも不明 | 片方だけ | 両方が読める | 複雑さを保ったまま固有価値が立つ |
| 読者参加・余白 | 誤解を招く省略 | 一方的説明 | 問い・予測の余地 | 読者の経験と意味が共振する |
| 圧縮と声 | 冗長または別人の声 | 情報過多・型過多 | 簡潔で自然 | 少ない言葉で多くが動き、声も残る |

合格条件:

- 合計18点以上
- 0点の項目がない
- 「忠実性」「目的・読み手適合」は各3点

点数は品質の代用ではなく、弱い場所へ戻るための診断として使う。

## 3. 修正先の決め方

| 弱い項目 | 戻るパス | 修正の焦点 |
|---|---|---|
| 忠実性 | Brief、Pass 1 | 事実台帳、保持／省略／提案の区別 |
| 目的・読み手適合 | Brief、Pass 3 | 読後行動、地と図、媒体 |
| 関係発見 | Pass 2、4 | 周辺情報、BPTの構造対応 |
| 視点転換・生成性 | Pass 5、7、8 | 異質な軸、原型、不足、遠い見立て |
| 構造 | Pass 5、6、10 | 分類、三点の型、時間軸 |
| コードとモード | Pass 7、8 | 仕様とらしさ、述語の重なり |
| 読者参加・余白 | Pass 3、9、10 | 開示順、問い、ナレーター |
| 圧縮と声 | 収束工程 | 比喩を一系列へ、重複削除、語彙を元文へ戻す |

## 4. 監査用の差分記録

必要な場合だけ、次の形式で示す。

| 元文の要素 | 編集後 | 扱い | 使用メソッド | 注記 |
|---|---|---|---|---|
| 数値・事実 | 同じ内容 | 保持 | 01 | 表現のみ調整 |
| 暗黙の関係 | 中心命題 | 顕在化 | 02、03 | 新事実ではない |
| 改善案 | 新規文 | 提案 | 05、06、07 | 実施済みと書かない |
| 比喩 | 新規文 | 見立て | 04、08 | 証拠ではない |

「付加価値」は、追加した文字数ではなく、元文では見えなかった関係・区別・可能性が、元の事実から追跡可能な形で立ち上がったかで判定する。
