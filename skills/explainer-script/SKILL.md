## なぜこのスキルが要るか（Claude の素の癖）
何も指示しないと Claude は「結論から言うと」で答えを先に渡し、見出しで項目を並べ、仕様の数字を列挙し、比較表を置き、「現時点では判断できません」で中立に閉じる。読み物としては正しいが、**最後まで聞く理由が無く、数字が耳に残らず、解説者の視点も無い**。このスキルはその癖を一つずつ置き換える。

## 手順

### 1. 材料集め（事実シート）
- テーマの一次資料を集める: 発表文・当事者の発言・仕様表・論文・決算・公式ドキュメント。二次報道は「世間の見方」の材料にだけ使う。最新ニュースは WebSearch で確認し、記憶で書かない
- 事実シートを作る。1行に「事実／数字／出典名／日付」。数字は単位まで書く
- 次の4つを探して印をつける。台本の山場になる
  - **食い違い**: 見出し・世間の受け取りと、一次資料の中身のずれ（例: 「新チップで対抗」→実は既存チップ2個）
  - **違和感の数字**: 片方だけ伸びた・桁が合わない数字（例: 容量+33%なのに帯域2倍）
  - **反転材料**: 「実は相手が先」「その『初めて』は限定つき」「対立相手は顧客でもある」
  - **人**: 二つの陣営をつなぐ人物・経歴
- 事実が足りない・確認できない場合は、作文で埋めずに「未確認」と書いてユーザーに伝える

### 2. 設計（台本を書く前に、この表を作ってユーザーに見せてもよい）
1. **タイトルの問い**を1文で決める（「〇〇は△△に勝てるのか？」「なぜ〇〇なのか？」）
2. **謎**: 食い違いから「なのに〜と言う。それは何なのか」という問いを作る。冒頭で2つまで約束する
3. **問いの連鎖**: 謎→答え→その答えから出る次の素朴な疑問→答え…を5〜8段つなぐ。各段の終わりの問いが次の段の見出しになる
4. **回収位置**: 冒頭の謎は中盤（全体の4割前後）で回収し、回収した答えから次の謎を出す。最後まで引っ張らない
5. **たとえ1系統**: 中心概念を1つのたとえにし（机と書庫など）、後の概念はその延長で言う（書庫への道→車線→制限速度）。たとえを途中で乗り換えない
6. **反転を2〜3回**配置する（自分で作った構図を自分で崩す）
7. **反対側の最強の言い分**を1段入れる
8. **結論の言い換え**: タイトルの問いを、分析で分かった本当の問いに言い換える（「勝てるか」→「誰がより安く越えるか」）
9. **見るべき3点**: 後で当たり外れが確認できる具体的な観点（価格・第三者測定・採用事例など）。ニュースでないテーマ（仕組み・ノウハウ）では「自分で確かめるべき3点」にする

### 3. 執筆の規則
- **答えを先に言わない**。冒頭は「問い→世間の見方→『ところが』」
- **見出しの羅列にしない**。段と段は問いでつなぐ（「では〜は？」「でも、なぜ〜？」）
- **数字は単独で出さない**。必ず「倍率」「身近な量（クレカの1/5・小説8冊）」「前に出た数字との比較」のどれかと組にする。1段に出す新しい数字は3つまで
- **封筒の裏計算を声に出す**。結論の数字は過程つき（35GB → 毎秒245回 → 7万回 → 約300倍）
- **一次資料を名指しする**（「Google の発表文には」「〇〇氏はこう言っています」「〇〇大の2024年の論文によると」）。発表文の強い言葉（初・最速・対抗）は検証してから使う
- **抽象の前に具体物**（実物・映像・現場）。専門用語は、出した直後に一言で言い換える
- **擬人化は1〜2回まで**効かせる（「コアは遊んでいる」）
- **割り引く点を示してから持論を言い切る**。「個人的には〜だと思います」。「判断できません」だけで終わらない
- **話し言葉**: 〜なんです／〜でしょう？／〜ですよね。1文は短く（目安40字）。台本には表・箇条書き・カッコ書き・記号を入れない（記事版では表を1つまで可）
- 長さの目安: 話し言葉で約350字が1分

### 4. 自己点検（出す前に全部確かめる）
- [ ] 冒頭30秒で、タイトルの問いと「ところが」の食い違いが出ているか
- [ ] 冒頭の謎を中盤で回収し、そこから次の問いが出ているか
- [ ] 段の切れ目がすべて問いでつながっているか（見出しの羅列になっていないか）
- [ ] 単独の数字が残っていないか（全部、比較か換算と組になっているか）
- [ ] たとえが1系統で通っているか
- [ ] 反転が2回以上あるか／反対側の最強の言い分があるか
- [ ] 一次資料が名指しされ、強い言葉が検証されているか
- [ ] 割り引く点と持論の両方があるか
- [ ] 締めに「見るべき3点」と「問いの言い換え」があるか
- [ ] 事実シートに無い事実を作っていないか（出典の無い数字はゼロか）
- [ ] 「結論から言うと」「判断できません」「いかがでしたか」が残っていないか

## 出力
- 既定は**動画台本**（話し言葉・段ごとに目安の時刻）。「記事で」と言われたら同じ構成で読み物にする（見出しは問いの形にする）
- 台本の後に短く添える: 使った一次資料の一覧（名前と日付）／未確認の事実／自己点検の結果
- 手本動画の文章は引き写さない。借りるのは構成と技法だけで、文章は毎回テーマに合わせて書き下ろす

## 使い分け
- 動画・Podcast の中身を知りたい → 要約用のスキルや手順を使う（このスキルではない）
- 新しいテーマで解説を作りたい → このスキル
- 手本を増やしたい（別の好きな動画の型を足す）→ その動画を文字起こしし、references/ に同じ形式の分析を追加して、手順2・3に差分だけ足す
- 図やイラストを添える記事にするとき → 図は「たとえ1系統」の場面ごとに1枚。段の問いに答える図だけを置き、飾りの図は置かない
