# 試作: explainer-script で別テーマ（約5分台本）
テーマ: 4時間の動画を文字起こしする「分割」の仕組み（作者が実装した分割機能の、実装と実測値だけを材料にした）

## 設計表
- タイトルの問い: 4時間の動画、切って分ければ済むのでは？
- 食い違い: 「切るだけ」のはずが、切ったら文が途中で消えた／重ねて切ったら今度は二重になった
- 謎（冒頭で約束）: ①なぜ切ると文が壊れるのか ②重ねたのに二重になったのはなぜか
- たとえ1系統: 長い巻物を何人かで手分けして書き写す（切れ目・のりしろ・のりしろの二重・人物の呼び名）
- 反転: ①無音で切れば安全→語り続ける動画には無音が少ない ②重ねれば安全→重ねたせいで二重
- 反対側の言い分: 単語ごとの時刻を使えば正確に切りそろえられる（でも処理が大幅に遅くなる）
- 問いの言い換え: 「どこで切るか」→「切った後、どちらの写しを信じるか」
- 見るべき3点: 話者番号の揃い方／重なりに出てこない話者／つなぎ目の前後10秒

## 台本

[0:00] 4時間の動画を文字起こししたい。でも使っている文字起こしの仕組みは、一度に3時間までしか受け付けません。なら、半分に切って2回にすればいい。そう思いますよね。
実際にやってみました。2時間ちょうどのところで、ばっさり2つに。ところが、できた文字を読むと妙なんです。つなぎ目のところで、話の途中の一文がまるごと消えていました。切っただけなのに、なぜ文が消えるのか。そして、それを直そうとして重ねて切ったら、今度は同じ話が二回出てきた。今日はこの二つの謎を追います。

[0:45] 文字起こしを、長い巻物を何人かで手分けして書き写す仕事だと思ってください。巻物をはさみで切って、前半をAさん、後半をBさんに渡します。
問題は、はさみを入れた場所です。言葉の真ん中で切ると、Aさんの手元には文の頭だけ、Bさんの手元には文の尻尾だけが残ります。どちらも半端な切れ端なので、意味の通る文として書き写せない。だから一文が消えたんです。

[1:20] では、どこで切ればいいのか。答えは、話が途切れたところ、つまり無音です。巻物でいえば段落と段落の間ですね。
今回の仕組みでは、切りたい位置の前後2分、合わせて4分の範囲から、いちばん長い無音を探して、その真ん中で切ります。国会の審議、27分の音声で試すと、2か所の切れ目はどちらも、委員長が名前を呼んでから答弁が始まるまでの、あの一瞬の間に落ちました。人間が切るならここ、という場所です。

[2:00] でも、ここで一つ不安が残ります。語り続ける動画には、そんなきれいな間が少ない。もし無音が見つからなかったら？
そこで、のりしろを付けます。Aさんには切れ目より1分先まで、Bさんには切れ目より1分前から渡す。2分ぶん、同じところを二人とも書き写すわけです。こうすれば、切れ目で言葉が半端に切れても、どちらかの手元には必ず文がまるごと残ります。音声の文字起こしではよく知られた定石で、ずらしながら重ねて読む方式として、広く使われています。

[2:45] これで解決、のはずでした。4時間1分の動画を、7313秒のところで2つに分け、全部で約49分。ところが、つなぎ目を読むと、約8秒ぶんの話が二回出てきたんです。
原因は、のりしろそのものでした。Aさんは切れ目をまたぐ長い一文を、最後まで書きました。Bさんも同じ部分を、少し違う区切り方で書き始めた。二人の写しは、時間で見ると2割ほどしか重なっていません。だから「時間が半分以上重なったら同じ発話」という最初の規則では、別物に見えてしまったんです。

[3:30] ここで発想を変えます。時間ではなく、文字を見比べる。Aさんの写しの終わりの方と、Bさんの写しの始まりの方に、同じ8文字以上の並びがあれば、Bさんの頭の重複を切り落とす。NVIDIA の音声認識モデル Canary の論文と同じ考え方です。
実際に切り落としたのは50文字。つなぎ目は「宇宙人なら」から「まだ進化を生き延びた」へ、一続きになりました。

[4:05] ちなみに、もっと正確な方法もあります。単語一つずつの時刻を出させて、ミリ秒単位で切りそろえる方法です。ただ、それをやると処理が一件ずつになり、時間が大きく延びます。4時間の動画を毎回待つ身としては、文字の照合で十分、というのが今回の判断です。

[4:30] まだ残る弱点もあります。話している人の番号です。AさんとBさんは、それぞれ自分の写しの中で「1番の人、2番の人」と呼び名を付けます。のりしろで同時に話している人どうしは対応づけられますが、のりしろに一度も出てこない人は、前半と後半で別の番号になってしまう。国会の例では、1人が2つの番号に分かれました。

[4:55] 個人的には、今回いちばんの学びは、問題の中心がはさみの位置ではなかったことです。切る場所を選んでも、のりしろを付けても、最後に問われるのは、重なったところでどちらの写しを信じるか。長い音声を扱うなら、見るべきは三つ。話者の番号がそろっているか。のりしろに出てこない人がいないか。そして、つなぎ目の前後10秒を、一度は自分の目で読むことです。

## 自己点検
- 冒頭の問い+「ところが」: あり（0:00）／謎の回収: 謎①を1:20、謎②を3:30で回収し、それぞれ次の問いへ
- 段の切れ目: すべて問いか「ところが」でつながる／単独の数字: なし（2時間→半分、8秒→二回、22%→2割、50文字→つなぎ目の文）
- たとえ: 巻物の書き写しで最後まで通した／反転: 2回（無音が少ない・重ねたせいで二重）／反対側の言い分: 単語時刻
- 持論と見るべき3点: あり／禁句（結論から言うと 等）: なし
