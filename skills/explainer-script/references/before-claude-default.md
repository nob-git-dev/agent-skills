## オープニング
皆さんこんにちは。今回は、Google が11月9日に発表した新しいAIチップ「TPU 8i Max」と「TPU 8TX」について解説します。
結論から言うと、今回の発表は「新しいチップ」ではなく、既存チップの組み合わせによる新製品です。その狙いは「メモリの壁」と呼ばれる課題への対応にあります。順番に見ていきましょう。

## 1. 発表の概要
Google は4月に TPU 8T（学習用）と 8i（推論用）を発表しており、今回はそれに続く追加モデルです。
- **TPU 8i Max**: 8i チップを2個、1つのパッケージにまとめたもの。長いコンテキストの処理を狙う
- **TPU 8TX**: 8T と同じチップに、機密コンピューティング機能を組み合わせたもの
Google の上級副社長 Amin Vahdat 氏によれば、トークンあたりの処理速度は従来と同じです。

## 2. メモリの壁とは
AIチップには、チップ内部の高速だが小容量な SRAM と、外部の大容量だが比較的遅い HBM があります。8i の場合、SRAM は 384MB、HBM は 288GB です。
大規模言語モデルは、トークンを1つ生成するたびにモデルの重みをメモリから読み出す必要があります。そのため、計算能力よりもメモリ帯域が性能のボトルネックになります。これが「メモリの壁」です。
例えば 700億パラメータのモデルを4ビットで保持すると約35GBになり、8i のメモリ帯域では1秒に約245回しか読み出せません。計算能力だけなら7万回以上可能なので、約300倍の差があります。
UC Berkeley の2024年の論文によれば、過去20年で計算能力は約6万倍、メモリ帯域は約100倍しか伸びていません。

## 3. KVキャッシュとエージェントの影響
実際のサービスでは複数ユーザーのリクエストをまとめて処理（バッチ処理）することで効率を上げています。しかし、会話ごとに蓄積される KV キャッシュはまとめることができません。
KV キャッシュはコンテキスト長に比例して増加します。130億パラメータのモデルで8,000トークンを処理すると約6.7GB になります。Gemini は100万トークンに対応しているため、さらに大きな容量が必要です。
加えて、AIエージェントの普及により、Google によるとエージェントのトラフィックはこの1年で7,800%以上増加しました。

## 4. TPU 8i Max の仕組み
8i Max はチップ2個分なので、計算能力・SRAM（768MB）・メモリ帯域（17.2TB/s）がそれぞれ2倍になります。一方、HBM 容量は 288GB から 384GB と33%の増加にとどまります。
つまり、容量よりも帯域を優先した設計です。これにより、1つの会話の速度は変わらないものの、同時に処理できる会話やエージェントの数が増えます。
また、8i は前世代比で SRAM を3倍に増やしており、より大きな KV キャッシュをチップ上に載せられます。

### なぜ2チップ構成なのか
半導体はリソグラフィ装置で一度に露光できる面積に上限があり（レチクル限界、26mm×33mm）、またチップが大きくなるほど歩留まりが下がります。そのため、複数のダイを1パッケージにまとめるチップレット方式が採用されています。なお、この方式は NVIDIA が Blackwell（2024年）で先に採用しています。

## 5. TPU 8TX と機密コンピューティング
8TX は、使用中のデータをハードウェアで保護する「機密コンピューティング」に対応します。
- チップあたり 12.6 PFLOPS（4ビット）、HBM 216GB
- AMD 第5世代 EPYC CPU と組み合わせ、CPU-TPU 間の通信を暗号化
- 主なターゲットは政府・金融機関
- ネットワークは Boardfly 構成で、最大ホップ数を16から7に削減
ただし、NVIDIA はすでに Blackwell で機密コンピューティングを提供しています。

## 6. NVIDIA との比較
| 項目 | TPU 8i Max | NVIDIA Rubin |
|---|---|---|
| HBM 容量 | 384GB | 288GB |
| メモリ帯域 | 17.2TB/s | 19.2TB/s |
| 計算性能 | 非公表 | 50PFLOPS（スパース時） |

NVIDIA は Groq の技術を約200億ドルでライセンス取得し、SRAM ベースの LPU を Rubin と組み合わせる構成を進めています。両社とも「2ダイ構成」「SRAM の強化」「処理の分担」という共通点があります。
また、NVIDIA には CUDA というソフトウェア上の強みがありますが、Google は PyTorch を TPU で動かすツールをオープンソースで公開しています。

## 7. 課題と今後
- 価格や第三者ベンチマークは未公表
- 提供開始は来年
- TPU の在庫はすべて契約済みで、生産能力が制約になっている
- Google は NVIDIA の GPU も大量に購入・提供しており、競合であると同時に顧客でもある

## まとめ
今回の発表は、新チップではなく既存チップの組み合わせによって、メモリの壁という課題に対応するものでした。NVIDIA に勝てるかどうかは現時点では判断できませんが、AIチップの競争軸が計算性能からメモリ効率へと移りつつあることを示しています。
今後は、価格、第三者による性能評価、そして TPU への移行事例に注目したいところです。
