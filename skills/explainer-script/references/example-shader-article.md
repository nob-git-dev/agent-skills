# 記事版の例: シェーダー・Tensor Core・TPU・NPU

全文（イラスト10枚つき）: https://github.com/nob-git-dev/agent-skills/blob/main/docs/examples/shader-article/README.md

依頼は「シェーダーとは何か、どう進化したか、行列計算をどうやっているか、TPU・NPU とどう違うか説明して」。ニュースではなく仕組みの解説なので、締めは「自分で確かめるべき3点」にした。

## 設計表
- タイトルの問い: 絵を描く部品は、なぜ AI の主役になったのか
- 謎（冒頭で2つ約束）: ①「影をつける係」がなぜ AI の計算をしているのか ②最新 GPU で AI を計算しているのは、じつはシェーダーではない
- たとえ1系統: 教室。生徒＝計算する部品、本棚＝メモリ、班の机＝共有メモリ、はんこ＝Tensor Core、バケツリレー＝シストリックアレイ
- 問いの連鎖: 何をしていた？→最初から何でも計算できた？→絵でない計算をどうやらせた？→AI の計算の正体は？→シェーダーは行列をどう計算？→最新 GPU は何が変わった？（謎②の回収）→TPU はどこが違う？→NPU は？→全部 TPU にすれば？→結局何が違う？
- 封筒の裏計算: 4096³＝約687億組 vs 数字5000万個（4096回の使い回し）／素朴なら1374億往復＝約2700倍／65536×7億×2＝約92兆＝論文の 92 TOPS
- 反転: 主役はもうシェーダーではない／GPU は行列専用装置を自分の中に取り込んだ／TPU を作った Google も GPU を買っている
- 反対側の最強の言い分: 新しい計算の形はまず GPU で動く・CUDA の蓄積
- 人: Ian Buck（Brook → CUDA）がグラフィックスと汎用計算をつないだ
- 問いの言い換え: 「どれが速いか」→「同じ数字をどこで何回使い回せる形か」
- 自分で確かめるべき3点: TOPS はどの部品・どの精度か／メモリ帯域／使いたいソフトが動くか

## 図の置き方
段の問いに答える図だけを、その段の中に1枚ずつ置いた（たとえの全体像、点ごとの陰影、年表、係の札、行列の1マス、往復の削減、はんこ、バケツリレー、TPU と NPU、まとめの軸）。図の中の言葉も本文と同じたとえで統一する。
